### Scope of this License (`src/ruby/`)
This license applies to the entire **Ruby** and **Ruby GG** studio editor, including:
- `src/ruby/editor/`: Main IDE window, tab manager, document viewer, virtual text buffers, and schema analyzers.
- `src/ruby/panels/`: Scene hierarchy, inspector, asset browser, audio viewer, console, lighting, local history, and template palettes.
- `src/ruby/graph/`: `Graphy` node graph engine, custom Qt canvas, and visual scripting editors.
- `src/ruby/render/`: 3D viewport shader pipeline, lighting rigs, SSAO, particle engines, and post-processing passes.
- `src/ruby/viewport/`: 3D viewport widgets, Raylib picking math, and intelligent camera-adaptive gizmos.
- `src/ruby/caver/`: Host runtime integration and visual engine host.
- `src/ruby/emulator/`: Embedded engine preview pod and shared memory frame receiver.
- `src/ruby/tools/`: Ground mesh studio and scene asset authoring tools.
- `src/ruby/database/`: Engine symbol databases and FileRift language services.
